# IBM Full Stack Developer Certification Projects
 This repository contains links to some interesting projects developed throughout the program.

## 1.   Developing Front-End Apps with React
- 🎟️ ReactConf-Planner is a React-based app for effortless event planning. Users can select venues, add-ons, and meals while viewing a detailed summary of their choices. Built for React practice, it emphasizes component-based architecture, state management, and a user-friendly experience.
🔗 [ReactConf-Planner](https://github.com/StivenHenao/ReactConf-Planner)

- 🌱 A React practice project featuring a plant store with a shopping cart. It includes dynamic UI rendering, state management with React Hooks and Redux, and GitHub Pages deployment.
🔗 [e-plantShopping](https://github.com/StivenHenao/e-plantShopping)

## 2.   Developing Back-End Apps with Node.js and Express
- 📚 A backend project developed as part of my certification in Node.js and Express backend development.  
This RESTful API allows users to search for books by ISBN, author, or title, and lets authenticated users manage reviews (add, update, and delete).  It includes session handling, JWT-based authentication, and asynchronous operations using Promises and async/await.
🔗 [Express Book Review API](https://github.com/StivenHenao/expressBookReviews)

## 3. Django Application Development with SQL and Databases
- 🎓 This is a web-based online course platform built with Django. It allows users to register, enroll in courses, take quizzes, and track their results. The app features user authentication, instructor management, and exam submission functionality.  

🔗 [OnlineCourseApp – Django Learning Platform with Exams & Enrollments](https://github.com/StivenHenao/OnlineCourseApp)

- 💼 Customer 360 is a minimalist Customer Relationship Management (CRM) app that lets users manage customers and log their interactions. Built with Django, this project supports multiple communication channels and provides summaries of recent engagement activity.  

🔗 [Customer 360 – Mini CRM with Django](https://github.com/StivenHenao/customer360)

## 4. Full Stack Application Development Capstone Project
- 🚗 A cloud-hosted web app where users can explore U.S. car dealerships, read and submit reviews, and view AI-generated sentiment analysis. Built with Django and IBM Cloud technologies, including Cloud Functions, Cloudant, and Watson NLU. Developed as part of the IBM Full Stack Cloud Developer Capstone to demonstrate backend integration, serverless computing, and data-driven features.
🔗 [AutoDealersHub](https://github.com/StivenHenao/AutoDealersHub)
